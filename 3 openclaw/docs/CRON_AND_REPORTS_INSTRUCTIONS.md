# Инструкция по Cron-отчетам

1. Самый простой способ: Шепните боту в Telegram: "Бот, пиши мне каждый день в 20:00: 'Жду отчет за день!'"
2. Сложный способ: В Web UI зайдите в Cron Jobs, добавьте задачу на `0 20 * * *` с экшеном на сообщение.
3. Бот сам поймет цифры из вашего голосового ответа и сохранит их в память.
