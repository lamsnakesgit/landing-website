# Настройка Cline: Изображения и Пользовательские API

## 1. Поддержка изображений (картинок) в Cline
Да, Cline отлично работает с изображениями, как и Antigravity. Ошибка на вашем скриншоте (`[OPENROUTER] 404 No endpoints found that support image input`) возникает потому, что выбранная бесплатная модель (`glm-4.5-air:free`) **не поддерживает функцию Vision (распознавание изображений)**.

**Как исправить:**
Вам нужно переключиться на модель, которая поддерживает обработку изображений.
Примеры подходящих моделей:
- **Anthropic**: `claude-3-5-sonnet-20240620`, `claude-3-opus-20240229`
- **OpenAI**: `gpt-4o`, `gpt-4-vision-preview`
- **Google**: `gemini-1.5-pro`

Для этого:
1. Откройте настройки Cline (значок шестеренки).
2. Выберите провайдера (например, OpenRouter) и в выпадающем списке выберите одну из "Vision"-моделей.
3. Теперь при вставке изображения в чат модель сможет его проанализировать.

## 2. Настройка кастомного эндпоинта (dmxapi / poloapi) с Claude Opus 
Для работы с пользовательскими API-прокси (такими как dmxapi или poloapi), в Cline есть встроенная поддержка любого API, совместимого с форматом OpenAI.

**Пошаговая настройка:**
1. Откройте настройки Cline.
2. В верхнем меню **API Provider** выберите **OpenAI Compatible**.
3. Появятся три главных поля для заполнения:
   - **Base URL (URL эндпоинта)**: Вставьте сюда адрес вашего `dmxapi` или `poloapi`. 
     *Важно:* Адрес обычно должен заканчиваться на `/v1` (например, `https://api.poloapi.com/v1` или `https://dmxapi.com/v1` — скопируйте точный адрес из личного кабинета провайдера).
   - **API Key**: Вставьте ваш авторизационный ключ от провайдера (dmxapi / poloapi).
   - **Model ID**: Введите название модели. Если нужна Claude Opus, обычно это `claude-3-opus-20240229` (уточните точное внутреннее название "opus 4.6" в документации прокси).

После этого нажмите кнопку **Done** внизу. Теперь ваши запросы будут идти через dmxapi/poloapi к нужной модели!
