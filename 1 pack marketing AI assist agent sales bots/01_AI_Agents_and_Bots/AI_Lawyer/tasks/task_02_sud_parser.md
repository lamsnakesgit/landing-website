# Task 02: Парсер Судебного кабинета (Playwright)

## Цель (Goal)
Написать скрипт-скрейпер на Python с использованием `playwright-python`, который зайдет на портал Судебного кабинета (`office.sud.kz`), авторизуется (используя наш работающий на фоне эмулятор NCALayer из Task 01), найдет судебное дело по заданному ИИН и скачает прикрепленный PDF файл решения.

## Техническое Задание (Requirements)
1. **Подготовка Playwright:**
   - Установить `playwright` (через pip) и запустить `playwright install chromium` для установки движка.
2. **Логика Авторизации:**
   - Скрипт должен зайти на `https://office.sud.kz/`.
   - Нажать на кнопку "Войти" / "Войти через ЭЦП".
   - *Важный нюанс:* В этот момент фронтенд Судебного кабинета отправит WebSocket-запрос на `localhost:13579`. Если наш `ncalayer_mock.py` запущен, он ответит заглушкой. Нужно пронаблюдать, как отреагирует сайт, и если он запрашивает путь к файлу, передать его.
3. **Поиск и Скачивание (Основной MVP флоу):**
   - Перейти в раздел "Поиск судебных дел" (Судебные акты).
   - Найти поле для ввода ИИН/БИН участника. Ввести тестовый ИИН (попросим у юзера позже, пока можно захардкодить пустую строку или тестовое значение).
   - Нажать поиск.
   - Спарсить результаты: найти первую ссылку на дело.
   - Нажать на дело, найти ссылку/кнопку на скачивание документа (Обычно кнопка "Скачать судебный акт" или иконка PDF).
   - Сохранить скачанный PDF-файл в локальную папку `01_AI_Agents_and_Bots/AI_Lawyer/downloads/cases/`.

## Ожидаемый результат (Deliverables)
- Файл `01_AI_Agents_and_Bots/AI_Lawyer/src/sud_parser.py`.
- Папка `downloads/cases/` для сохранения PDF.
- Скрипт должен корректно работать в `headless=False` режиме (чтобы мы видели браузер глазами при тестах).
- Заполни отчет в `PROGRESS.md`.
