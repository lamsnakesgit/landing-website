# Task 01: NCALayer WebSocket Эмулятор (pykalkan)

## Цель (Goal)
Написать Python-скрипт (на базе `websockets` и `pykalkan`), который поднимет локальный сервер на порту `13579`. Этот сервер должен уметь отвечать на запросы от браузера (Судебный кабинет) так, как это делает оригинальный десктопный NCALayer, и подписывать XML-запросы ключом `GOST.p12`.

## Техническое Задание (Requirements)
1. **Библиотеки:** 
   - Установить `websockets` и `asyncio`.
   - Использовать библиотеку `pykalkan` (установка через pip: `pip install pykalkan`).
   - *Важно: `pykalkan` требует бинарников KalkanCrypt C++ SDK от НУЦ РК. Пока пишем логику (stub) или поднимаем сервер, который загружает библиотеку (пусть падает с понятной ошибкой, если бинарников нет).*
2. **WebSocket Сервер:**
   - Сервер должен слушать адрес `127.0.0.1` (или `localhost`) на порту `13579`.
   - Обработка CORS: должен разрешать подключения с `office.sud.kz` и других порталов.
3. **Логика NCALayer:**
   - Оригинальный NCALayer общается через JSON.
   - Ожидаемые команды: `getActiveTokens` (вернуть список путей к ключам или просто "PKCS12"), `createCAdESFromBase64` (принять Base64, подписать через pykalkan с использованием файла ключа, вернуть подписанный Base64).
   - Ключ и пароль к нему можно временно захардкодить в `.env` (например, путь `TEST_KEY_PATH=./test_gost.p12`, пароль `TEST_KEY_PASSWORD=123456`).
4. **Ожидаемый результат (Deliverables):**
   - Файл `01_AI_Agents_and_Bots/AI_Lawyer/src/ncalayer_mock.py`.
   - Логирование всех входящих JSON-запросов от браузера (чтобы мы могли реверс-инжинирить Судебный кабинет).
   - Напиши отчет о результатах в файл `PROGRESS.md`.
