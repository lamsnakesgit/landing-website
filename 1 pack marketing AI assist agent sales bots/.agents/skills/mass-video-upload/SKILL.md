# Mass Video Upload Skill

## Назначение
Этот скилл предоставляет готовый и отказоустойчивый скрипт для массовой загрузки видео (на YouTube и Google Drive) через API-шлюз Maton AI. 

## Проблема, которую решает скилл
Раньше скрипты загрузки буферизировали вывод и выдавали все ссылки разом в конце (что неудобно, когда загрузка длится долго), а также не сохраняли метаданные файла. В этом скрипте добавлено:
1. Вывод ссылки **моментально** после загрузки каждого отдельного файла.
2. Использование параметра `flush=True` в Python для живого обновления логов агента.
3. Отсчет прогресса `[1/19]` и замер времени загрузки каждого файла.
4. Вывод кликабельных локальных путей в формате `file:///`.
5. **Автоматическое извлечение дат создания и изменения оригинального файла и добавление их в описание (description) на YouTube и Google Drive.**

## Как использовать
1. Найди скрипт в этой папке: `scripts/mass_upload.py`.
2. Перед использованием скопируй его в корень проекта, либо запускай напрямую из этой папки.
3. Открой скрипт и впиши абсолютные пути к нужным файлам в массивы `youtube_files` и `google_drive_files`.
4. Запусти команду `python3 -u mass_upload.py`, чтобы Python гарантированно выдавал логи в реальном времени.
5. Наблюдай за процессом через `manage_task` (если запускаешь в фоне) или просто читай логи по мере появления ссылок.

## Требования
В корне проекта должен лежать `.env` с актуальным `MATON_API_KEY`.
