# Headless Mode (Cline CLI)

## Cline CLI на VPS

- **Путь:** `/usr/bin/cline`
- **VPS:** `<YOUR_VPS_IP>`
- **SSH:** `ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP>`

## Основные опции

| Опция | Описание |
|---|---|
| `cline [prompt]` | Запуск задачи сразу |
| `-a, --act` | Режим act (выполнение) |
| `-p, --plan` | Режим plan (планирование) |
| `-y, --yolo` | Авто-approve всех действий (HEADLESS!) |
| `--auto-approve-all` | Авто-approve с интерактивностью |
| `-t, --timeout <sec>` | Таймаут в секундах |
| `-m, --model <model>` | Выбор модели |
| `-c, --cwd <path>` | Рабочая директория |
| `--continue` | Продолжить последнюю задачу |
| `-T, --taskId <id>` | Возобновить задачу по ID |

## Команды

| Команда | Описание |
|---|---|
| `task\|t [options] <prompt>` | Запустить новую задачу |
| `history\|h` | История задач |
| `config` | Конфигурация |
| `auth` | Аутентификация |
| `mcp` | Управление MCP серверами |

## Примеры использования

```bash
# Простой запуск
ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cline 'проверь мой код на ошибки'"

# Полный headless (авто-approve)
ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cline -y 'проверь код'"

# С таймаутом 5 минут
ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cline -y -t 300 'почини тесты'"

# В конкретной директории
ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cline -y -c /opt/myproject 'сделай рефакторинг'"

# Продолжить задачу
ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cline --continue"
```

## Регулярные задачи (cron)

```bash
# Каждую ночь — проверка кода
0 3 * * * ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cd /opt/myproject && cline -y -t 600 'проверь код на ошибки и исправь'"

# Каждый понедельник — рефакторинг
0 2 * * 1 ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cd /opt/myproject && cline -y -t 1800 'проведи рефакторинг'"

# Ежедневный отчёт
0 9 * * * ssh -i ~/.ssh/id_ed25519 <SSH_USER>@<YOUR_VPS_IP> "cd /opt/myproject && cline -y -t 300 'составь отчёт о состоянии проекта'"
```

## Когда использовать

- Ночной рефакторинг — пока спишь, код улучшается
- Автоматическая проверка — после каждого коммита
- Ежедневные отчёты — по расписанию
- Массовые изменения — когда нужно обработать много файлов

## Когда НЕ использовать

- Задача проще — использовать более лёгкие инструменты
- Нужен контроль — использовать интерактивный режим
- Нет таймаута — задача может зависнуть

## Правила

- MUST использовать `-y` для полного headless режима
- MUST ставить таймауты чтобы задачи не висели бесконечно
- SHOULD использовать `-c` для указания рабочей директории
- SHOULD проверять результат через `history` после выполнения
- NEVER запускать опасные команды без таймаута
