# SMM Brand AI: Контент-завод & Автопостинг сторис

Эта подсистема спроектирована для автоматизации SMM как стратегического инструмента маркетинга. Вся работа ориентирована на долгосрочный результат: выстраивание доверия, рост вовлеченной аудитории, регулярные прогревы и генерацию лидов/продаж с последующей монетизацией (включая YouTube, TikTok, Instagram и Telegram).

---

## 📈 1. Архитектура аналитики и метрик

Основная цель сбора статистики — отслеживание динамики каждой единицы контента для выявления форматов с наивысшим охватом (views) и вовлеченностью (ER - Engagement Rate). Эти данные позволяют ИИ-планировщику генерировать целевой контент-план на следующую неделю.

### Схема базы данных (Supabase)
Мы сохраняем данные в две таблицы:
1. `smm_posts` — реестр опубликованных постов/видео на всех платформах.
2. `smm_metrics_history` — ежедневные снимки метрик (просмотры, лайки, комменты, репосты, сохранения) для отслеживания динамики во времени.

### Метрики по платформам:
* **Telegram**: Просмотры (`views`), реакции (`reactions`), комментарии (`replies`), пересылки (`forwards`).
* **YouTube (видео и Shorts)**: Просмотры (`views`), лайки (`likes`), комментарии (`comments`).
* **Instagram (Reels и посты)**: Просмотры (`views`), лайки (`likes`), комментарии (`comments`), сохранения (`saves`), репосты (`shares`).
* **TikTok**: Просмотры (`views`), лайки (`likes`), комментарии (`comments`), репосты (`shares`).

## 🚀 2. Модуль автопостинга сторис (Publishers)

Модуль позволяет ИИ-ассистенту и воркфлоу n8n публиковать контент (фото/видео с подписью) в сторис (статусы) в WhatsApp, Telegram и Instagram.

* **WhatsApp Status**: Отправляется через инстанс Evolution API с помощью эндпоинта `/message/sendStatus/{instance}`.
* **Telegram Stories**:
  - В каналы: через Bot API (`sendChatStory`).
  - В профиль пользователя: через `Telethon` (клиентское API, отправка историй от имени аккаунта).
* **Instagram Stories**: Авторизуется под вашим аккаунтом через библиотеку `instagrapi`. Чтобы избежать блокировок от Instagram из-за частых авторизаций, используется сохранение сессии в `session.json`.

## 🧠 3. ИИ-планировщик контента (Planner)

Скрипт `ai_content_planner.py` анализирует исторические данные из Supabase:
1. Извлекает топ-10 единиц контента с максимальным охватом и топ-10 с максимальным ER за последний месяц.
2. Отправляет эти темы, форматы и зацепы в Gemini с промптом, настроенным на методологию высоких чеков (позиционирование "виртуальных сотрудников", продажи через доверие).
3. Генерирует готовый контент-план: темы, форматы (Reels/Shorts, посты, статьи), тезисы, воронки (цель контента) и призывы к действию (CTA).

## 🛠️ 4. Переменные окружения (.env)

Для активации всех возможностей добавьте в файл `.env` следующие ключи:

```env
# YouTube Data API v3
YOUTUBE_API_KEY=your_google_cloud_youtube_api_key

# Telegram Telethon (для сбора аналитики и автопостинга Stories)
TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
TELEGRAM_SESSION_NAME=smm_brand_ai_session

# Instagram (для автопостинга через instagrapi)
INSTAGRAM_USERNAME=your_username
INSTAGRAM_PASSWORD=your_password

# RapidAPI (для парсинга Instagram и TikTok, если выбран этот метод)
RAPIDAPI_KEY=your_rapidapi_key
```

*Примечание: Хранение сессий Telethon и Instagram происходит локально в файлах сессий в папке проекта, что снижает риск блокировок.*
