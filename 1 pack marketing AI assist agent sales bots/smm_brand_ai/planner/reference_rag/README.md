# RAG-база успешных референсов контента

Эта папка используется как локальная база знаний (RAG) успешных креативных решений, сценариев и видеороликов конкурентов.

## Структура файлов
Каждый файл анализа сохраняется под именем `analysis_YYYYMMDD_name.md` и содержит:
1. Текст/транскрипт оригинального успешного видеоролика.
2. Статистику (просмотры, лайки, ER).
3. Наш исходный сценарий.
4. Разбор структуры Hook -> Retention -> CTA от ИИ (Gemini).
5. Итоговый готовый сценарий для нашего ролика.

## Как использовать
При генерации нового контент-плана или написании сценариев для новых видеороликов ИИ-планировщик может считывать файлы из этой папки, чтобы:
- Использовать уже сработавшие хуки (Hooks) в качестве шаблонов.
- Повторять успешные схемы удержания внимания (Retention).
- Использовать рабочие призывы к действию (CTA), которые привели к продажам.
