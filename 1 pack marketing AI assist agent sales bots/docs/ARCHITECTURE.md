# Архитектура проекта "AI Lawyer"

## Концепция
AI Lawyer — это SaaS-платформа для автоматизации рутинной работы юристов в Казахстане. 
Вместо ручного поиска по ИС «Параграф» (prg.kz) или агрегаторам вроде Oksima / BestProfi (которые ищут нерелевантно), ИИ-юрист на базе LLM и RAG предоставляет мгновенные, смысловые ответы с подбором судебной практики.

## Основные компоненты
1. **Scraping Engine (Парсинг первоисточников)**
   - **office.sud.kz (Судебный кабинет):** Основной донор данных. Требует обхода NCALayer, ЭЦП-авторизации и защиты Cloudflare.
   - **ИС Параграф / Adilet:** База нормативно-правовых актов.

2. **AI & RAG Core (Интеллектуальное ядро)**
   - Векторная база данных (Pinecone / pgvector) для хранения судебных решений.
   - LLM (Gemini / GPT) для смыслового анализа дел.

3. **Backend & Orchestration**
   - n8n / LangChain для управления пайплайнами данных.
   - FastAPI / Python для кастомных парсеров.

4. **Frontend & Monetization**
   - Web-интерфейс / Telegram-бот для конечного юриста.
   - Модель SaaS (подписка) для B2B (юр. фирмы) и B2C (физ. лица).
