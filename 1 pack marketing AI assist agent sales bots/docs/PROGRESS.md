## ⚠️ Проблемы и решения (Issues & Solutions)
- **Фоллбэк API ключей**: Ошибка OpenAI 401 перехватывается, система мгновенно переключается на Vertex AI (Gemini 2.5 Flash) по HTTP без сбоя процесса.
- **Обогащение в 10 потоков**: Использован `ThreadPoolExecutor` с кэшированием результатов в `enrichment_cache.json` для максимальной скорости.
