# PROGRESS & LOGS

## 🚀 Что обновлено и сделано (Wins)
1. **Парсер HH.ru / HH.kz (`hh_parser.py`)**:
   - Переведен с заблокированного API на прямой и надежный HTML-скрапинг вакансий и работодателей.
   - Извлекает компании, контакты (email, телефон, HR), ссылки на вакансии и описание требований.
   - Успешно обрабатывает запросы без блокировок 403 Forbidden.

2. **Парсер Adata.kz (`adata_parser.py`)**:
   - Реализован скрапинг через Playwright на базе `pk.adata.kz`.
   - Автоматически находит компании по нишам в Казахстане, вытягивает БИН/ИНН, ФИО руководителя (ЛПР), адрес, город и контактные данные.

3. **Парсер Threads.net (`threads_parser.py`)**:
   - Реализован браузерный скрапинг через Playwright (`headless=True`).
   - Автоматически находит профили маркетологов, экспертов по ИИ и ботам, вытягивая никнеймы, описание профилей и ссылки для аутрича.

4. **Агрегатор и ИИ-анализатор (`daily_lead_aggregator.py`)**:
   - Собирает лидов ежедневно по 6 ключевым запросам: `ии`, `разработка`, `боты`, `маркетинг`, `контекстная реклама`, `ии контент`.
   - Реализован каскадный ИИ-анализ (OpenAI GPT-4o-mini с автоматическим фоллбэком на Vertex AI / Gemini 2.5 Flash).
   - Формирует для каждого лида:
     - Боли бизнеса и проблемы
     - Угол захода (Outreach Angle)
     - Гранд Слэм Оффер (Что именно предложить компании)
     - Драфт 1-го сообщения для связи в WhatsApp / Telegram
   - Сохраняет результаты в `03_Marketing_and_Sales/daily_leads/YYYY-MM-DD/`:
     - `leads_summary.md` (Главная сводка и таблицы)
     - `leads.csv` & `leads.json` (База данных лидов)
     - `details/*.md` (Персональные файлы с оффером и драфтом сообщения на каждый лид).

## ⚠️ Проблемы и ограничения (Issues)
- **OpenAI API Key**: Предоставленный ключ в `.env` вернул ошибку `401 Unauthorized`. Система автоматически переключилась на локальный Vertex AI Service Account (`vertex_sa.json`), который работает стабильно и быстро.
- **Индикация Threads**: Threads.net отдает публичные профили без авторизации, но некоторые аккаунты не содержат прямых телефонов в шапке (контакты устанавливаются через 1-е сообщение в директ/комментарии).
