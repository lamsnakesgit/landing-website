## ✅ Что сделано

### Инфраструктура
- Docker-контейнер `kalkan_parser` на VPS `151.241.100.226`
- Авторизация через ЭЦП (KalkanCrypt), C-wrapper `kalkan_sign`
- CAPTCHA решается через `ddddocr`
- Оркестратор `run_all_years.py` (2026→2015), фон через `tmux`

### Парсер `sud_parser.py`
- Авторизация RichFaces AJAX + fallback POST
- Категория: Трудовые споры (`142030000100000000`)
- Обход пагинации, скачивание PDF/DOCX через капчу (5 попыток)
- HTML-карточка каждого дела (`_case.html`) — пруф ссылки на оригинал
- Метаданные в `labor_cases_{YEAR}.json`
- Retry: 3 попытки per дело, 5 per капча

### БД и промпты (субагенты)
- `ai_lawyer/supabase/schema.sql` — PostgreSQL + pgvector
- `ai_lawyer/prompts/extract_case_data.md` — извлечение данных из PDF
- `ai_lawyer/prompts/search_query.md` — переформулировка запроса юриста
- `ai_lawyer/prompts/answer_with_cases.md` — финальный ответ с прецедентами
- `ai_lawyer/extractor.py` — извлечение через Gemini Flash

### Исправленные баги
- `[Errno 2] No such file or directory` → `os.makedirs(PDF_DIR, exist_ok=True)`
- "Ложный кэш" (дела отмечались скачанными без файла) → сброс + перезапуск
- 3 Docker-зомби → убиты, парсер запущен чисто

## [2026-07-05] Мультикатегорийный парсинг + журнал в Google Docs (Подряд / ЧСИ / Корпоративные)

**Категории:** `sud_parser.py` был жёстко привязан к одной категории ("Трудовые споры"). Добавлены `CATEGORY_ID` / `CATEGORY_PREFIX` env-переменные (дефолт сохраняет старое поведение), имена выходных файлов теперь `{CATEGORY_PREFIX}_cases_{YEAR}.json` вместо хардкода `labor_cases_*`, чтобы категории не затирали друг друга. `run_all_years.py` пробрасывает эти переменные в `docker run -e`.

Найдены/подтверждены ID категорий под конкретные запросы юриста:
- `142030001200070000` — Мердігерлік шарт / По договору подряда
- `142040000300010000` — Об оспаривании действий ЧСИ (по факту дал 0 дел за 2024-2026 — категория реально малонаселена в публичном банке, это не баг)
- `142030003000000000` — Корпоративные споры

**Баг №1 (параллельная Gemini/Antigravity-сессия):** её `mass_downloader.py` не применяет реально фильтр категории в AJAX-запросе — все 3 категории и оба года вернули идентичные 10 "левых" дел (с меткой совсем другой категории). Файлы `data/2025`, `data/2026` от неё — не использовать. Она же выдала несуществующую ссылку на Google Doc (галлюцинация).

**Баг №2 (свой, в `push_to_doc.py`):** MIME-тип для загрузки в Google Drive определялся по имени файла (`.pdf.docx` → `application/pdf`), хотя реальный формат — это magic bytes. Проверка `xxd`/`file` показала, что скачанные "решения" на самом деле настоящие `.docx` (`PK\x03\x04`, "Microsoft Word 2007+"), а не PDF. Из-за неверного MIME Google Drive пытался рендерить Word-файл как PDF — превью показывало только 1 страницу, дальше "не удалось загрузить". Тот же класс проблемы уже чинили раньше в `upload_cases_maton.py` (коммит "Fix file extension mime type check") — там уже было готовое правильное решение (проверка magic bytes + публичные права доступа на файл), просто не переиспользовали. Исправлено: `push_to_doc.py` теперь определяет тип по первым байтам файла (`%PDF` → pdf, `PK\x03\x04` → docx), выставляет `permissions: role=reader, type=anyone` на каждый загруженный файл, и берёт точную ссылку на оригинал через `param1` дела (`https://office.sud.kz/form/courtActs/lawsuitList.xhtml?param1=...`) вместо общей ссылки на форму поиска.

**Maton API:** подтверждено, что `gateway.maton.ai` поддерживает не только Sheets/Drive, но и полноценный Google Docs API (`POST /google-docs/v1/documents` create, `POST /google-docs/v1/documents/{id}:batchUpdate` для вставки текста через `endOfSegmentLocation`). Раньше в проекте это не использовалось.

**Инфраструктурные грабли:**
- Долгие job на VPS запускать только через `tmux`, не `nohup &` — голый nohup погибал без вывода при закрытии SSH-сессии.
- `pkill -9 -f <строка>` при вызове через `ssh ... "pkill -9 -f mypattern"` может убить сам себя, если `mypattern` совпадает с текстом собственной command line — выглядит как случайный обрыв SSH (exit 255). Фикс: `pkill -9 -f 'my[p]attern'` (bracket-trick).
- На локальном Mac периодически кончается место на диске (0 байт свободно), что ломает вообще все инструменты, требующие временных файлов. Похоже на снапшоты Time Machine — `sudo tmutil deletelocalsnapshots /` помогает.
