## 15-06-2026: Тишина бота при работе с Evolution API в Docker
- **Проблема:** Бот-агент не получал вебхуки от Evolution API (полная тишина в логах, хотя Evolution отправлял данные на `http://localhost:3000/webhook`).
- **Что пробовали:**
  1. Проверили логи PM2 и Evolution API (Evolution отправлял, PM2 ничего не принимал).
  2. Пробовали использовать IP докер-моста `172.17.0.1:3000`. Не помогло.
  3. Проверили код `app.js` на наличие ошибок парсинга (нашли старую ошибку `TypeError`, но она не была причиной тишины).
- **Что получилось/нет:** Запросы продолжали уходить в пустоту без выдачи HTTP ошибок (Connection Refused не было).
- **Что привело к решению:** Выяснилось, что Evolution API запущен с `network_mode: host`. В таком режиме внутри Docker `localhost` резолвится по протоколу IPv6 как `::1`, в то время как Node.js сервер (PM2) по умолчанию слушает интерфейс IPv4 (`127.0.0.1`). Они находились на разных протоколах. 
- **Решение:** В настройках инстанса Evolution API URL вебхука был жестко изменен на явный IPv4 адрес `http://127.0.0.1:3000/webhook` (или публичный IP сервера). Использовать `localhost` запрещено.
