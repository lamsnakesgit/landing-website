# 🚀 План реализации: Полный сбор базы судов (2015-2026) и Индексация

Этот план описывает, как мы автоматизируем выкачивание ВСЕХ трудовых дел за последние 10 лет, загрузим их в твой Google Drive и сформируем удобный реестр в Google Docs для проверки.

## 🎯 Цели
1. Выкачать документы за все года (до вчерашнего дня текущего 2026 года).
2. Автоматически загружать их в папку `ии_юрист` в Google Drive.
3. Автоматически создать Google Doc (Реестр), в котором будет таблица со всеми ссылками (на оригинал и на GDrive) и префиксами для удобной проверки юристом.
4. Настроить RAG-базу (векторный поиск).

---

## 🛠 Предлагаемые изменения

### 1. Доработка парсера (Все года)
Парсер сейчас качает только один год за запуск.
* **[MODIFY]** Скрипт запуска `deploy.py` (или создадим новый `run_all.py`), который будет по очереди запускать Docker-контейнер передавая ему `PARSE_YEAR=2026`, потом `2025`, `2024` и так до `2015`.
* **[NEW]** Файлы будут сохраняться с префиксами года и номера дела, например: `2026_7519-26-00-2_1664_Решение.docx`. Это решит вопрос идентификации.

### 2. Скрипт синхронизации с Google Drive & Google Docs
Создадим отдельный Python скрипт (через Maton API), который работает параллельно или после парсинга:
* **[MODIFY]** `upload_to_gdrive.py` будет доработан.
* Скрипт берёт скачанный файл, грузит в GDrive, получает публичную ссылку.
* Скрипт формирует строку для отчета: `ID дела | Год | Ссылка GDrive | Оригинальная ссылка на Судебный кабинет`.
* В конце скрипт через Maton API загружает этот отчет как **Google Doc** и кидает тебе ссылку в Telegram. Юрист сможет открыть этот Doc и "потыкать" ссылки для проверки.

### 4. "Скриншоты" (HTML копии страниц) и Метаданные
Ты просила сохранять скрины страницы. Поскольку наш парсер работает без браузера (напрямую общается с сервером кодом для скорости), сделать картинку (PNG) он не может. 
Но мы сделаем **лучше**: мы будем сохранять **полную HTML-копию страницы дела**. 
Ты сможешь открыть этот файл, и он будет выглядеть точь-в-точь как страница сайта Судебного кабинета. Эти HTML-файлы мы тоже будем грузить в твой Google Drive рядом с DOCX-документами.

**Метаданные для векторов:** Обязательно! Мы вытащим Судью, Истца, Ответчика и Суть, и прикрепим их к векторам в базе. Юрист сможет искать: *"Найди мне дела, где судья Иванов отказывал по статье 52"*.

> [!IMPORTANT]
> **Ограничение по времени и месту:** 
> Выкачивание 10 лет может занять **сутки-двое** непрерывной работы VPS. Чтобы сервер не "упал" от нехватки памяти, мы будем автоматически **удалять скачанные файлы с VPS** сразу после их успешной загрузки в твой Google Drive.

## ✅ Принятые решения (По твоим ответам)
1. **Очистка диска:** Файлы удаляем с сервера (VPS) после загрузки в Google Drive.
2. **Года:** База суда содержит дела вплоть до **сегодняшнего дня (2026 год)**. Мы начнем парсинг с 2026 года и пойдем вниз (2025, 2024...).
3. **Проверка:** В Google Doc будет таблица с номером дела (ID) и ссылкой на Google Drive. Юрист сможет проверить оригинальность, просто вбив ID в Судебный кабинет.
4. **Метаданные:** Мы забираем всю карточку дела целиком, а не только PDF/DOCX.
