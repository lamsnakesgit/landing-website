# Полное руководство по системе LeadGen OS: Сбор, HH Playwright-кликер и OSINT Обогащение

---

## 1. Сбор контактов с HH.ru через Playwright (Браузерная автоматизация)

### Как работает кликер контактов на HH.ru:
1. **Открытие страницы вакансии/компании:** Playwright загружает DOM-дерево вакансии.
2. **Клик по кнопке «Показать контакты»:** 
   ```python
   # Автоматический клик по кнопке контактов рекрутера/компании
   contacts_btn = page.query_selector('[data-qa="vacancy-contacts__button"]')
   if contacts_btn:
       contacts_btn.click()
       page.wait_for_selector('[data-qa="vacancy-contacts__email"]')
   ```
3. **Извлечение раскрытых данных:**
   - 📞 Телефон рекрутера / компании (например, `+7 (777) 123-45-67`)
   - ✉️ Прямой e-mail контакта
   - 👤 ФИО контактного лица / HR-директора

## 2. Поиск контактов через OSINT ("Глаз Бога" и открытые базы)

### Что цепляет OSINT по номеру или названию компании:
* **Теги и Имя из GetContact / баз:** Как зафиксирован владелец номера (например, *"Алексей Директор Маркетинг"*).
* **Связка Telegram ID ↔ Телефон:** Превращение юзернейма `@alexey_ceo` в реальный номер телефона через Telethon / OSINT-резолверы.
* **Кадастровые и Юридические данные:** Извлечение БИН/ИНН через `PK Uchet`, поиск ФИО первого руководителя и его коммерческих структур.
* **Доменная разведка (`xurlfind3r` / `Crawl4AI`):** Сканирование подвалов сайтов, файлов `.pdf` (КП, счета) и страниц `/contacts` на наличие прямых WhatsApp-ссылок `wa.me/7...`.

## 3. Режимы работы лидогенерации

| Режим | Источник | Метод извлечения | Результат |
| :--- | :--- | :--- | :--- |
| **HH Contact Clicker** | HH.ru / HH.kz | Playwright клик по кнопке "Контакты" | Телефон рекрутера + Email |
| **PK Uchet Miner** | PK Uchet / Adata | API / Scrapling по БИН | ФИО Директора + Юр. адрес + Тел. |
| **Web & OSINT Miner** | Crawl4AI + DDGS | Поиск `site:t.me` + Regex на сайте компании | Прямой WhatsApp / Telegram ЛПР |
| **TG Chat Interceptor** | B2B ТГ-чаты | Telethon Userbot | Сообщения-запросы ("Ищу ботовода/маркетолога") + ТГ аккаунт |

## 4. Как проверяется валидность контакта

Перед добавлением в `leads_qualified.json` контакт проходит автоматический фильтр:
1. **Формат телефона:** Проверка по E.164 (`+7XXXXXXXXXX`).
2. **Наличие WhatsApp:** Запрос в Evolution API / Check-endpoint.
3. **Наличие Telegram:** Проверка `@username` или валидного t.me link.
4. Если ни одного контакта нет — лид **НЕ попадает** в итоговую рассылку и отправляется в фоновый бэклог.
