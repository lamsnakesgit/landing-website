# Лог: Google Cloud Voices & Voice Cloning Plans

## Wins (Успехи)
- Выяснили, как использовать премиальные голоса Google Cloud (Neural2, Chirp3-HD) в рамках $300 Free Trial.
- Подтвердили, что 1 млн символов — это ~10-15 часов аудио.
- Подсчитали, что на $300 фри-триала можно сгенерировать 18.75 млн символов (~280 часов) элитной озвучки, не потратив ни копейки с карты.
- Проаналидировали текущие голоса в n8n (ru-RU-DmitryNeural от Microsoft и старые WaveNet от Google) и подготовили план их замены на Neural2 или Chirp3-HD.

## Problems / Issues (Проблемы и их решения)
- **Дублирование сообщений в Telegram:** n8n дублировал ответы бота из-за конфликта нод (Telegram Tool внутри ИИ-агента + обычная Send Message нода в конце ветки).
- **Недоступность Claude 3.5:** Модели Anthropic (Claude 3.5 Sonnet / Opus) не входят в $300 Free Trial, так как это партнерские модели. Гугл требует перевести аккаунт в платный режим (Upgrade Billing) для их использования.
- **Ошибка 403 Forbidden (BILLING_DISABLED) в ноде TTS:** Возникала из-за использования старого `API_KEY` в URL, который был привязан к старому проекту с истекшим $300 триалом. **Решение:** перейти на новый проект и использовать JSON-ключ Service Account.
- **Ошибка 403 Forbidden (unregistered callers) в ноде TTS:** Возникла при настройке HTTP Request в n8n из-за двух ошибок:
  1. В URL остался "хвост" `?key`, из-за которого Google игнорировал Service Account и отклонял пустой ключ. **Решение:** полностью удалить `?key` из ссылки, оставив только `.../text:synthesize`.
  2. В настройках n8n Credential не был указан Scope. **Решение:** в настройках ключа в поле Scope жестко прописать `https://www.googleapis.com/auth/cloud-platform`.
- **Ошибка "number of function response parts is equal to the number of function call parts" в Vertex AI (Gemini):** Краш ИИ-Агента в n8n при попытке прочитать историю чата. Возникает, когда в памяти остался сломанный вызов инструмента (Tool был вызван, но ответ не записался).
  - **Решение:** Полный сброс истории (памяти) для данной сессии. Либо изменить Session ID в ноде Memory (добавив к нему `_v2`), либо вручную очистить базу данных (Supabase/Postgres), где хранится история переписки.

### 3. Нужно ли нажимать кнопку "Upgrade" (Апгрейд)?
**КАТЕГОРИЧЕСКИ НЕТ! Ни в коем случае не нажимай Upgrade.** 
- Пока ты сидишь на Free Trial (без апгрейда), Гугл **физически не может** списать ни одной копейки с твоей банковской карты. Даже если ты случайно потратишь все $300, сервисы просто остановятся и выдадут ошибку, но карта будет в безопасности.
- Если ты нажмешь **Upgrade**, твой аккаунт перейдет в "Платный режим". Подарочные $300 останутся, но если они закончатся, Гугл автоматически начнет доить твою банковскую карту за каждый запрос. 
- **Вывод:** Сидим на Free Trial до победного конца (83 дня или пока не кончатся 300 баксов). 

### 4. Алгоритм (Итог): Как заставить Google TTS работать в n8n без ошибок 403?
Мы перепробовали разные варианты и нашли единственный железобетонный путь, так как n8n багует с OAuth Scope для Service Account:
1. Зайти в Google Cloud Console (выбрать проект с активным Free Trial).
2. Перейти в **APIs & Services -> Credentials**.
3. Создать **API Key** (кнопка Create Credentials -> API Key).
4. Ограничить ключ (API restrictions -> выбрать Cloud Text-to-Speech API). Не ставить галочку "Authenticate API calls through a service account".
5. В n8n в ноде HTTP Request:
   - **Authentication**: `None`
   - **URL**: `https://texttospeech.googleapis.com/v1beta1/text:synthesize?key=ТВОЙ_НОВЫЙ_КЛЮЧ`
   - В теле запроса (`Body`) передавать настройки голоса (например, `ru-RU-Chirp3-HD-Charon`).
