## 🚀 Что нужно сделать СЛЕДУЮЩИМ АГЕНТОМ (план действий)

### Шаг 1 — Исправить .env (2 мин)
```bash
nano /путь/.env
# убрать точки из ключей, убрать пробел в EVOLUTION_INSTANCE
```

### Шаг 2 — Развернуть файлы на VPS (5 мин)
```bash
# Скопировать два файла на VPS:
scp 06_Scripts_and_Tools/food_delivery_leads.json user@vps:/путь/
scp 06_Scripts_and_Tools/food_outreach_sender.py user@vps:/путь/
# Убедиться что .env с правильными ключами тоже есть на VPS
```

### Шаг 3 — Тест перед запуском (5 мин)
```bash
# На VPS запустить 1 тестовое сообщение самому себе:
python3 food_outreach_sender.py
# Смотреть лог - отправилось ли на первый номер
```

### Шаг 4 — Настроить крон на VPS (2 мин)
```bash
crontab -e
# Добавить (9:00 по Алматы = 04:00 UTC):
0 4 * * * cd /путь/к/папке && python3 food_outreach_sender.py >> logs/food_outreach.log 2>&1
```
