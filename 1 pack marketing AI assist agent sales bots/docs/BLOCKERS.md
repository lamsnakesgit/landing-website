# BLOCKERS (Блокеры и Ограничения)

1. **IP Блокировка шлюзом РК (ЕШДИ)**: 
   - Сервер авторизации `idp.egov.kz` и `egov.kz` блокируют подключения с иностранных IP адресов (включая наш текущий VPS). Выдает ошибку 403 / "Веб-страница заблокирована". 
   - *Решение:* Первичная авторизация вынесена на локальную машину с чистым IP.

2. **Жизненный цикл сессий**:
   - Время жизни QR-кода: ~2-3 минуты.
   - Время жизни сессии кабинета (`office.sud.kz` / `SSO`): ~24 часа. 
   - *Проблема:* Отсутствует долгоживущий API токен, требуется регулярное ручное обновление сессии.

3. **Динамический рендеринг (XHR/AJAX)**:
   - Судебный кабинет использует современные JS-фреймворки. Данные о судебных делах не лежат в HTML-коде страницы, а подгружаются динамическими POST-запросами. 
   - *Решение:* Обычный парсинг BeautifulSoup не сработает. Необходимо использовать Playwright с перехватом сетевых ответов (`page.on("response")`), чтобы ловить чистый JSON с делами.
