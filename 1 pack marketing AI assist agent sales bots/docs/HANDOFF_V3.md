# HANDOFF (Версия 3)

## Контекст Проекта
Мы разрабатываем автоматизированную систему (AI Agent) для сбора и анализа судебных актов по трудовым спорам из Судебного кабинета РК (`office.sud.kz`).

## Текущий Статус (Что уже сделано)
1. **Преодолена защита ЕШДИ**: Выявлено, что шлюз РК (`idp.egov.kz`) блокирует доступ с иностранных IP-адресов.
2. **Локальная авторизация**: Создан скрипт `local_qr_login.py`, который запускается на локальном Mac пользователя, открывает браузер, позволяет отсканировать QR eGov, перехватывает `SSO` куки и отправляет их на VPS по SCP.
3. **Обход защиты на сервере**: Скрипт `scripts/parse_court_acts.py` на VPS загружает эти куки, заходит напрямую на `https://office.sud.kz/main` (минуя `idp.egov.kz`) и успешно получает доступ (статус "АВТОРИЗОВАН").

## Технические Ограничения (Блокеры)
- **Срок жизни сессии**: Куки живут около 24 часов. Архитектура SaaS невозможна без перехода на Chrome Extension (плагин) или получения ЭЦП. Для локального MVP приемлемо сканировать QR раз в день.
- **Динамический контент**: HTML-таблицы с судебными делами загружаются асинхронно через XHR/AJAX. Парсить чистый HTML бесполезно.

## Задачи для Агента V3 (Next Steps)
