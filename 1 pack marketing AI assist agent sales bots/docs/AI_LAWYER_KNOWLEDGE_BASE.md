# Анализ конкурентов и бизнес-контекст AI Lawyer (Казахстан)

## Существующие решения на рынке (Конкуренты)

1. **ИС «Параграф» (prg.kz)**
   *   **Статус:** Золотой стандарт на рынке РК, монополист по базе законов.
   *   **Проблема:** Поиск работает по старым алгоритмам (как в Google 2010 года). Юристу приходится вручную вбивать ключевые слова, перебирать сотни ссылок, скачивать документы и читать их глазами, чтобы найти нужную норму или прецедент. Никакого AI и смыслового (семантического) поиска нет.

2. **Oksima (Оксима) / BestProfi (БестПрофи)**
   *   **Статус:** Пытаются делать аналитику судебной практики и агрегировать судебные дела.
   *   **Проблема (Оксима):** Как мы выяснили, Оксима "так себе ищет". Поиск нерелевантный, система выдает много мусора, нет нормального AI-ответа на конкретный юридический вопрос. Юристу всё равно приходится делать много ручной работы.

## Наше решение: AI Lawyer (B2B SaaS)
*   **Цель:** Создать SaaS сервис (веб-платформу по подписке) для юристов, юридических фирм и физ. лиц.
*   **Функционал:** Полная автоматизация поиска по Судебному кабинету и базе Параграфа. 
*   **Как это работает:** Юрист задает вопрос естественным языком (например: "Какая актуальная судебная практика по взысканию долга без расписки, только по переписке в WhatsApp?"). Наш ИИ-агент (RAG) мгновенно анализирует тысячи реальных судебных актов, законы и выдает готовый ответ, подкрепленный ссылками на конкретные дела и статьи.
*   **Ценность:** Юрист экономит часы и дни на рутинном ресерче. Дела решаются быстрее, юрист зарабатывает больше, а физ. лица могут получить базовую консультацию без дорогого найма.

## Стратегический фокус для ИИ-Агентов
1. Любой ценой наладить бесперебойный парсинг `office.sud.kz` (Судебный кабинет). Без своей регулярно обновляемой базы судебных решений наш ИИ будет бесполезен.
2. Изучить обход WAF/Cloudflare и защиты NCALayer для сбора закрытых/открытых судебных документов.
3. Вся собранная судебная практика должна векторизоваться для RAG-системы.
