# Площадки для поиска жирных заказов на видеопродакшен (Тендеры и B2B)

## 1. Государственные закупки РК
**Сайт:** [goszakup.gov.kz](https://goszakup.gov.kz)
**Описание:** Главный портал госзакупок Казахстана. Министерства, школы, университеты и госучреждения заказывают здесь образовательный контент, имиджевые ролики и видеокурсы.
**Агрегация:** Доступно официальное **GraphQL API** (https://ows.goszakup.gov.kz/v3/graphql). HTML парсить не рекомендуется, так как API отдает всё в JSON быстро и чисто.

## 2. Портал закупок Самрук-Казына
**Сайт:** [tender.sk.kz](https://tender.sk.kz) (или zakup.sk.kz)
**Описание:** Закупки квазигосударственного сектора (Казахтелеком, КазМунайГаз, КТЖ и др.). Крупные бюджеты на корпоративное обучение и корпоративные видеоролики.
**Агрегация:** Официального API нет. Стоит защита от ботов и авторизация по ЭЦП. Парсится тяжело, лучше использовать Selenium/Playwright (как в b2b-lead-enricher) с обходом Cloudflare.

## 3. Евразийский электронный портал (ЕЭП)
**Сайт:** [eep.mitwork.kz](https://eep.mitwork.kz)
**Описание:** Коммерческие закупки и закупки недропользователей. Здесь часто ищут подрядчиков для частных крупных компаний.

## 4. B2B Базы данных (Прямые продажи)
- **Adata.kz / PK Uchet:** Поиск образовательных центров, ИП и ТОО, открывших ОКЭД по образованию или тренингам. 
- **hh.kz / hh.ru:** Компании, ищущие в штат "Видеомонтажера", "Motion-дизайнера" или "Продюсера курсов". Им можно продать автоматизацию или аутсорс дешевле найма сотрудника.
