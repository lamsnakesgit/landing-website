# Запрос "1_137" и Гибридная Архитектура Судебного Кабинета

## Суть проблемы
Юрист ищет прецеденты, используя жесткий текстовый поиск Судебного кабинета (Sud.kz).
Тестовый запрос с видео:
- **Основной поиск:** `признать незаконным и отменить государственной регистрации в правовом кадастре`
- **Категория дел:** `Все`
- **Резолютивная часть:** `удовлетворить`

Такой поиск выдает либо 0 результатов (из-за несовпадения окончаний), либо сотни дел, где эти слова встречаются в разных контекстах.

## Гибридная архитектура решения (Агент + Детерминированный скрипт)

Ни один ИИ не может напрямую "серфить" сложные закрытые госреестры с 100% стабильностью. Архитектура строится на принципе "Воронки":

### 1. Детерминированный Скрипт-Парсер (Инструмент/Tool)
Python-скрипт (Playwright/Puppeteer), развернутый на VPS.
- Принимает четкие параметры: `main_query`, `resolution_query`, `year`, `limit`.
- Выполняет логин в Судебный кабинет (обход капчи/Cloudflare).
- Вбивает фильтры, собирает ссылки на дела.
- Возвращает количество найденных дел. Если дел < `limit` (например, 50), скачивает PDF-файлы решений и переводит их в текст.

### 2. Умный Агент (Мозг системы)
Слой ИИ, с которым общается юрист (например, через Telegram-бота).
- Юрист дает задачу: "Найди 20 дел по отмене регистрации гаража, где иск удовлетворен".
- **Анализ и Сужение:** Агент вызывает скрипт-парсер с широкими ключами. Если парсер возвращает "Найдено 15 000 дел", агент либо самостоятельно сужает запрос (добавляет уточняющие слова), либо запрашивает уточнение у юриста (Region, точный тип объекта).
- **Глубокий анализ:** Когда парсер отдает текст 50 скачанных дел, агент прогоняет их через LLM с детальным системным промптом, оставляя только те 5-10 дел, которые реально подходят под сложный юридический контекст.
- **Генерация отчета:** Формирует Excel-таблицу по нужному ГОСТу.

## Преимущества подхода
- **Стабильность:** Скрипт не галлюцинирует при нажатии кнопок на сайте.
- **Точность:** ИИ ищет по смыслам, а не по окончаниям слов, но работает только с узкой (предварительно отфильтрованной) выборкой документов, что экономит токены и время.
- **Ожидания:** Клиент понимает, что система работает как "умный ассистент", а не как "магическая кнопка с 99% гарантией".
