# Беклог Идей и Доработок

## 1. Автономность через Telegram (Hermes / Cline)
- Сделать так, чтобы не нужно было сидеть за компом (web ui не нужен). 
- Всё общение идет только через Telegram-бота (типа агента Hermes).
- Бот сам всё кодит, собирает, монтирует и просто присылает готовые Reels прямо в личку.

## 2. ИИ-Ревьюер (Слой пред-анализа)
- Добавить слой проверки перед тем, как отправлять видео человеку.
- Gemini (или другая топ-модель цена/качество) отсматривает сгенерированный клип.
- Оценивает: качество мимики, ляпы генерации, вирусность, визуальный смысл.
- Если генерация плохая — ИИ сам пишет новый промпт и перегенерирует дубль.
- Если нормальная — отправляет пользователю на финальный аппрув (с возможностью внести правки в промпт).
