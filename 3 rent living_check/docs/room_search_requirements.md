# Требования к поиску комнаты (Алматы)

## Бюджет
- **Цена:** до 80 000 тенге (с учетом ком. услуг желательно)

## География (Квадрат)
- **Юг:** пр. Аль-Фараби
- **Восток:** пр. Достык
- **Север:** пр. Райымбек
- **Запад:** ул. Саина
- *Приоритет:* ближе к центру города.

## Условия проживания
- Строго **изолированная комната**
- **Без подселения** (жить одному в комнате)
- **Разрешено проживание для девушек**
- Наличие свободного места под рабочий стол (если его нет в комнате)
