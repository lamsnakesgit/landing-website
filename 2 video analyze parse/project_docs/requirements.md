# Требования к проекту "Система контроля качества продаж"

## 1. Общее описание
Создать систему, аналогичную "Clario", для автоматизации контроля качества продаж и частичной замены функций руководителя отдела продаж (ROP). Система должна анализировать диалоги менеджеров с клиентами, предоставлять отчеты, автоматически ставить задачи и эскалировать критические моменты.

## 2. Ключевой функционал

### 2.1. Анализ диалогов (Core Analytics)
-   **Источники данных:**
    -   Телефонные разговоры (записи аудио).
    -   Переписки в мессенджерах (WhatsApp, Telegram).
    -   Данные из CRM (статусы сделок, responsible manager).
-   **Анализ качества:**
    -   **Соответствие скрипту:** Выявление этапов продаж (приветствие, выявление потребностей, презентация, работа с возражениями, закрытие сделки).
    -   **Качество коммуникации:** Оценка эмпатии, структурированности речи, профессионализма, убедительности.
    -   **Дисциплина времени:** Скорость ответа на сообщения, отсутствие "глухих пауз", соблюдение регламентов касаний (например, 3 звонка за неделю, 5 сообщений).
    -   **Аргументация:** Качество аргументации цены, гарантий, партнеров.
-   **Оценка лида:** Определение качества incoming лида (0-100%) на основе заданных критериев (гео, демография, источник и т.д.). Анализ работы менеджера не проводится, если оценка лида ниже порога (например, 40%).
-   **Комплексная оценка:** Сводный балл менеджера на основе 13 параметров, сгруппированных в 3 подпоказателя (согласно описанию Clario).
-   **Выявление ошибок и рекомендаций:** Автоматическая генерация фидбека для менеджера.
-   **Причины отказа:** Категоризация и анализ причин, если сделка не закрыта.
-   **Анализ потребностей клиентов:** Выявление явных и неявных потребностей.
-   **Языковая поддержка:** Анализ казахского, русского, узбекского языков.

### 2.2. Агент "Супервайзер" (Supervisor Agent)
-   **Функция:** Автоматическая проверка сделок на критических этапах воронки продаж (например, "Закрыто нереализованно", "Ключевой этап").
-   **Действия:**
    -   Оценка "потенциала реанимации" сделки.
    -   **Автоматическое создание задач** в CRM для менеджера, если выявлены косяки или сделка имеет высокий потенциал.
    -   **Возврат сделки** в воронку из статуса "Закрыто нереализованно" при нарушении регламента.
    -   Эскалация критических моментов (например, менеджер пытается перевести клиента в свой личный WhatsApp, не отработал простое возражение) в Telegram-бот для ROP.
-   **Цель:** Снижение нагрузки на ROP, оперативная коррекция действий менеджеров.

### 2.3. Ежемесячная глубокая аналитика (Monthly Strategic Audit)
-   **Объект анализа:** Бизнес-модель компании, отдел продаж, маркетинг, продукт.
-   **Источники данных:** Агрегированные данные за месяц из всех сделок, диалогов, CRM.
-   **Анализ:**
    -   **Потребности клиентов (явные и неявные):** Для разработки маркетинговых креативов и доработки продукта.
    -   **Возражения клиентов:** Выявление частых возражений и подготовка готовых ответов.
    -   **Анализ эффективности:** Оценка работы каждого менеджера, сильные и слабые стороны.
    -   **Психотипы клиентов:** Глубинный анализ.
    -   **Конкурентный анализ:** Автоматический на основе данных диалогов.
    -   **Генерация one-page summary:** "Диагноз" бизнеса, план действий (action plan).
-   **Скрипты:** Автоматическое обновление и улучшение скриптов продаж на основе накопленных данных.

### 2.4. Агрегаторы источников данных (Data Aggregation)
-   **Интеграции:**
    -   CRM: Bitrix24 (приоритет), другие по запросу.
    -   Телефония: Требуется уточнить (Amo CRM, Voximplant, Mango Office, интеграция с мобильными).
    -   Мессенджеры: WhatsApp, Telegram.
-   **UTM-метки и теги:** Сбор данных об источнике лида для сквозной аналитики.
-   **Поля CRM:** Анализ и возможное автозаполнение полей в CRM на основе диалогов.

### 2.5. Timeline (Лента событий / Дашборды)
-   **Доступ для менеджеров:** Личный кабинет с рейтингом, аналитикой по их сделкам, фидбеком от "Супервайзера". Система мотивации.
-   **Доступ для ROP/руководства:** Общая аналитика, отчеты "Супервайзера", эскалации.
-   **Ежедневные отчеты:** PDF-отчеты от Telegram-бота о работе "Супервайзера".

### 2.6. API и Ценообразование
-   **API:** Предоставление API для интеграции с другими системами клиента, например, для привязки комплексной оценки менеджера (CES) к их системе мотивации.
-   **Модель ценообразования (ориентировочно, как в Clario):**
    -   **Pilot (2 недели):** $89 за менеджера (все включено: настройка, интеграция).
    -   **Подписка:** $89/мес (3 мес), ~$69/мес (6 мес), ~$49/мес (12 мес) за менеджера.

## 3. Технологический стек (предпочтительный)
-   **Ядро логики/аналитики:** Python (с библиотеками для работы с AI/ML), или нативные модули n8n.
-   **Автоматизация:** **n8n** (основной кандидат).
-   **AI/ML для анализа:** OpenAI API (GPT-4), Google Gemini, или другие LLM.
-   **MCP:** **Superpowers MCP** для расширения функциональности n8n.
-   **База данных:** PostgreSQL, MySQL.
-   **Хранение файлов:** Для отчетов (PDF), возможно, S3-совместимое хранилище.
-   **API:** RESTful API.
-   **Уведомления:** Telegram Bot API.
-   **Интерфейс (Dashboard):** React/Vue.js (если будет веб-интерфейс), или нативные дашборды n8n.
