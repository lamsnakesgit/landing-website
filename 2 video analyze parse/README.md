# Video Watermark Remover Bot

Telegram-бот для бесплатного снятия водяных знаков с видео (Sora, TikTok и др.).

## Структура проекта
- `src/` — Исходный код бота и движка Playwright.
- `downloads/` — Временная папка для скачанных видео.
- `logs/` — Логи работы и скриншоты ошибок.
- `configs/` — Место для конфигурационных файлов.
- `.env` — Ваши секретные ключи (Токен бота).

## Установка и запуск
1. Установите зависимости:
   ```bash
   python3 -m pip install -r requirements.txt
   python3 -m playwright install chromium
   ```
2. Настройте токен в `.env`.
3. Запустите:
   ```bash
   python3 src/bot.py
   ```

## Информация об API
Если вы хотите использовать прямые API вместо автоматизации браузера, обратите внимание на следующие сервисы (может потребоваться платная подписка):
1. **GhostCut (RapidAPI)** — Автоматическое удаление вотермарок и субтитров.
2. **Vmodel AI API** — Профессиональное решение для видео.
3. **Kie.ai** — Специализированное решение для Sora-видео.

Текущая реализация использует **Playwright** для обхода лимитов путем имитации новых сессий пользователей.
