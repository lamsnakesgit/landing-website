# Задача: безопасный удалённый ИИ-кодер через Telegram + n8n

## Что хочет пользователь

- Стабилизировать текущего Telegram-ассистента в `n8n`, который иногда «вылетает» и тупит.
- Понять, можно ли сделать удалённого ИИ-кодера, которому можно писать задачи с телефона.
- Добиться поведения уровня «удалённый coding agent»: принять задачу, спланировать, внести изменения, прогнать проверки и вернуть результат.
- Сделать всё **безопасно**.

## Текущие вводные

- Есть Telegram-бот/ассистент, связанный с `n8n`.
- В качестве мозга использовалась модель Gemini, но поток нестабилен.
- Нужен вариант, который можно расширить под API-модель и под удалённый запуск задач по коду.
- Обнаружен конфиг `n8nac-config.json` для `n8n-as-code`, указывающий на удалённый инстанс `https://n8n.aiconicvibe.store`.
- Локально **нет** синхронизированной папки `workflows`, а проверка инстанса в конфиге завершилась ошибкой `ENETUNREACH`.
- Пользователь хочет сделать **копию** ассистента для экспериментов с coding-agent логикой, при этом основной ассистент должен остаться в режиме только чтения / без рискованных изменений.

## Что считаем успехом

1. Есть понятная архитектура, как принимать задачи из Telegram.
2. Есть план диагностики текущего нестабильного `n8n`-потока.
3. Есть безопасная схема удалённого выполнения задач по коду.
4. Опасные действия не происходят без явного подтверждения.
5. Все изменения идут через Git-ветки, логи и аудит.

## Жёсткие ограничения

- Нельзя давать Telegram-пользователю прямой безлимитный shell-доступ.
- Нельзя позволять агенту свободно трогать все репозитории и все секреты.
- Нельзя пускать разрушительные команды без ручного подтверждения.
- Нельзя завязывать систему только на одном нестабильном workflow без логирования и retry-механик.

## Практический результат этого шага

- Подготовлен архитектурный план.
- Подготовлен пошаговый сценарий внедрения.
- Подготовлен walkthrough того, как такой агент должен работать в быту.
- Выполнен разбор найденного `n8n-as-code` конфига и подтверждено, что исходный workflow пока недоступен локально.
- Подготовлена стратегия, как делать отдельную копию ассистента с Cline-подобным режимом, не ломая основной сценарий.
