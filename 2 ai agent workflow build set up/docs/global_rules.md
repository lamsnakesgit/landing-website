# Глобальные правила проекта

В этом проекте действуют правила Antigravity, пользовательские надстройки и адаптированные правила из Cline.

## 1. Глобальные правила Antigravity (Встроенные)
Эти правила действуют по умолчанию для всех сессий:
- **Стиль общения**: Использование GitHub-style markdown, краткость, конструктивность.
- **Артефакты**: Обязательное создание `task.md`, `implementation_plan.md` и `walkthrough.md` для сложных задач.
- **Разработка**: Фокус на эстетике UI, SEO оптимизации, семантическом HTML и отказе от "заглушек".
- **Инструменты**: Использование MCP серверов (в данном случае `n8n-mcp`) и встроенных инструментов управления файлами/браузером.

## 2. Пользовательские правила (User Global)
Эти правила добавлены пользователем в настройки:
- **Логирование**: Всегда записывать обновления в `docs/log.md`.
- **Состав лога**: Список побед (wins), проблем (problems/issues).
- **Язык лога**: Дублирование записей на русском языке.

## 3. Правила из Cline (Адаптированные)
Эти правила были импортированы из файла `Cline Global Rules.docx`:
- **Язык**: Основной язык общения и комментариев в коде — **Русский**. Код (переменные, функции) — на английском.
- **Стиль кода**: Современный JS (ES2022+), лимит 50 строк на функцию, использование Brave Search при нехватке данных.
- **Авто-решения**: Принимать TypeScript и установку зависимостей автоматически; отказываться от React Compiler.
- **Контекст**: Автоматическое создание сводки переноса (handoff) при заполнении контекста более чем на 50%.
- **Разработка**: Интерфейсы должны быть на русском языке; полный отказ от маркетинговой информации и упоминаний провайдеров.
- **Внешние инструменты**: Обязательное использование Context7 MCP для поиска документации библиотек.

---

### Можно ли менять эти правила?
1. **Правила Antigravity и User Global**: Меняются в глобальных настройках приложения Antigravity на вашем компьютере.
2. **Проектные правила**: Вы можете редактировать этот файл (`docs/global_rules.md`) или создать `.clinerules` в корне проекта. Я буду учитывать их при работе в этом контексте.
